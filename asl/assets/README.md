Files in this folder

- `atlas.json`: one hand pose per sign, picked from the training data by `python -m asl.atlas`.
- `words.txt`: the 20,000 most frequent English words, taken from wordfreq 3.1
  (https://github.com/rspeer/wordfreq). The wordfreq data is licensed CC BY-SA 4.0,
  so this list is too.
